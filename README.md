# TOEFL 단어장

`index.html` 파일 하나로 동작하는 TOEFL 단어 학습 도구입니다. 설치도 서버도 필요 없고, 파일을 브라우저에서 열면 됩니다.

## 기능

- **md 등록**: 아래 형식의 md 파일을 넣으면 단어가 한꺼번에 등록됩니다. 등록 전에 분석 결과(단어·뜻·유의어·예문 개수, 오류, 이미 있는 단어)를 먼저 보여줍니다. 이미 등록된 표제어는 건너뜁니다.
- **단어 등록**: DAY(1~30), 표제어, 한국어 뜻(여러 개), 뜻별 유의어, 뜻별 예문을 직접 입력합니다. 한 번 고른 DAY는 다음 등록에도 유지됩니다.
- **시험**: 별점을 가중치로 한 번에 45문제를 출제합니다.
- **등록된 단어**: DAY별 탭, 검색, 별점 필터, 수정, 삭제.
- **백업**: 데이터 내보내기와 불러오기.

## md 형식

```
# DAY 1

## assure
- 뜻: 확신시키다
  - 유의어: convince, persuade, satisfy
  - 예문: The lawyer assured Tim that all his rights would be respected.
- 뜻: 보장하다
  - 유의어: guarantee
  - 예문: The lawyer assured Tim that all his rights would be respected.
```

- `# DAY n`은 다음 DAY 표시가 나올 때까지 아래 단어에 적용됩니다.
- 한국어 뜻마다 `- 뜻:` 줄을 따로 씁니다. 박스가 나뉜 뜻도, `;`로 나뉜 뜻도 각각 다른 뜻입니다.
- 쉼표(`,`)로 이어진 한국어 뜻은 한 뜻입니다.
- `;`로 나뉜 뜻처럼 예문이 하나뿐이면 같은 예문을 두 뜻에 반복해서 씁니다.
- `<!-- ... -->` 주석과 빈 줄은 무시합니다.

## 시험

- **표제어 한국어 뜻**: 뜻의 개수만큼 빈칸이 생깁니다. 직접 쓰고 정답과 비교해 스스로 채점하며, 전부 맞아야 정답입니다.
- **표제어 예문 빈칸**: TOEFL의 Complete the Words 방식입니다. 예문에서 표제어의 앞 절반(홀수 글자는 내림)이 주어지고, 빠진 글자만 씁니다. 두 단어 이상이면 단어마다 적용합니다. 철자가 정확하면 자동 정답이고, 아니면 정답을 보고 직접 채점합니다.
- **유의어**: 그 유의어가 속한 뜻의 한국어만 묻습니다. 표제어에 뜻이 여러 개여도 해당 뜻 하나만 묻습니다.

## 별점과 채점

별이 많을수록 모르는 항목입니다. 표제어(단어당 1개)와 유의어(하나하나)가 각각 별점과 시험 기록을 가지며, 시험이 끝날 때마다 다시 계산합니다.

| 기록 | 별점 |
| --- | --- |
| 시험 기록 없음 | ★★★ |
| 최근 5번 모두 정답 | ★☆☆ |
| 최근 5번 중 3번 이상 정답 | ★★☆ |
| 그 외 | ★★★ |

## 데이터 저장

데이터는 이 브라우저의 localStorage에 저장됩니다. 같은 파일 경로나 주소로 열어야 같은 데이터가 보이고,
다른 브라우저나 기기와는 공유되지 않습니다. 기기를 옮기거나 브라우저 데이터를 지우기 전에는 **백업** 탭에서 내보내기를 해두세요.
