# TOEFL 단어장

`index.html` 파일 하나로 동작하는 TOEFL 단어 학습 도구입니다. 설치도 서버도 필요 없고, 파일을 브라우저에서 열면 됩니다.

## 기능

- **단어 등록**: DAY(1~30), 표제어, 한국어 뜻(여러 개), 뜻별 유의어, 뜻별 예문.
  한 번 고른 DAY는 다음 등록에도 유지되고, 바꾸면 그 DAY가 다시 유지됩니다.
- **시험**: 별점을 가중치로 한 번에 45문제를 출제합니다.
  표제어는 한국어 뜻·예문 빈칸 문제, 유의어는 한국어 뜻만 묻습니다. 표제어와 유의어는 같은 급의 시험 항목입니다.
- **등록된 단어**: DAY별 탭, 검색, 별점 필터, 수정, 삭제.
- **백업**: 데이터 내보내기와 불러오기, 이전 버전(Next.js) 앱의 `.data/toefl-vocab.json` 가져오기.

## 별점과 채점

별이 많을수록 모르는 항목입니다. 시험이 끝날 때마다 항목별 기록으로 다시 계산합니다.

| 기록 | 별점 |
| --- | --- |
| 시험 기록 없음 | ★★★ |
| 최근 5번 모두 정답 | ★☆☆ |
| 최근 5번 중 3번 이상 정답 | ★★☆ |
| 그 외 | ★★★ |

한국어 뜻 문제는 정답을 확인한 뒤 직접 채점하고, 빈칸 문제는 정확히 쓰면 자동으로 정답 처리됩니다.

## 데이터 저장

데이터는 이 브라우저의 localStorage에 저장됩니다. 같은 파일 경로나 주소로 열어야 같은 데이터가 보이고,
다른 브라우저나 기기와는 공유되지 않습니다. 기기를 옮기거나 브라우저 데이터를 지우기 전에는 **백업** 탭에서 내보내기를 해두세요.
